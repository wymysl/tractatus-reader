- Explanation reads 2.027 as the payoff of a thirty-day-old flag rather
  than a fresh claim: "the fixed" is 2.026's word, "the existent" is
  2.024's (*besteht*, the same verb), and 2.027 asserts that neither
  names a property objects merely carry — both name the object itself.
  Traced this as the third of three predicates day 9 predicted would
  land on "object" in quick succession (simple, 2.02; substance, 2.021;
  fixed/existent, 2.027), arriving in the strongest form the run has
  taken, an outright identity rather than a further description. Flagged
  a grammatical point worth being exact about the day after a Parmenides
  Zen note: "sind Eins" is plural and stays plural — 2.027 does not
  collapse every object into one undivided whole, it asserts the
  identity object-by-object, which 2.0271's forthcoming object/
  configuration split requires.
- Zen note uses Aquinas's real distinction between essence and existence
  (*De Ente et Essentia* ch. 4; *Summa Theologiae* I, q.3, a.4): only God
  is *ipsum esse subsistens*, essence and existence identical in exactly
  one case, every creature composite by contrast. The disanalogy is the
  whole point — 2.027 asserts the identical-looking collapse (nothing
  distinguishes an object's fixity, existence, and the object itself) but
  strips the feature that gives Aquinas's version its force: uniqueness.
  Wittgenstein's identity holds across every object with no privileged
  exception, where Aquinas's holds in exactly one case and nowhere else.
  First use of Aquinas in this project. Considered and set aside
  Spinoza's essence-involves-existence claim (*Ethics* I, prop. 7) as a
  same-direction match that would confirm rather than test the reading,
  and as inside the five-day diversity window (day 32).
