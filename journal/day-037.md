- Explanation reads 2.0271 as the delivery of the oldest open thread this
  project has been carrying: day 2 named "object, state of affairs,
  configuration" as pairs still to come, day 8 sharpened that into a
  triad (fact/thing, atomic fact/existence, object/configuration), and

  what actually varies: not the object (2.027 already forecloses that),
  but which arrangement, out of 2.0141's fixed range of form, is
  currently combined — the same objects configured differently, not new
  objects appearing. Glossed the two-word care in "das Wechselnde,
  Unbeständige" the same way 2.027's note glossed "das Feste,
  Bestehende": changing marks that configurations differ from each
  other, variable (closer to *unbeständig*'s "not standing fast") marks
  that no single configuration is owed the permanence an object has —
  the room chapter 2 needs for the world to be contingent while
  substance stays fixed underneath it.
- Zen note uses Plato's Forms against the sensible world of becoming
  (*Republic* V, 477a–479e; VI, 509d–511e; *Timaeus* 27d–28a) as the
  older instance of a fixed/changing division. Located the disanalogy
  precisely: Plato's split crosses a real ontological gap (participation
  or imitation, two levels of being, the sensible demoted relative to
  the intelligible), where 2.0271's configuration is nothing but the
  fixed objects themselves, combined — no second, lesser realm, no
  copying relation, both sides full members of the world's furniture per
  2.0272 and 2.03 next. First use of Plato in this project, despite two
  earlier days (23, 28) treating adjacent fixed/changing and
  form/material questions without reaching for him.
