# Day 29 — 2026-08-17

## Authored

- Thesis 2.0232 (`content/day-029.md`): explanation, Zen note, method note.
- Explanation reads 2.0232 as 2.0231's abstract principle (material
  properties are posterior, made only by configuration) taken to its
  blunt, one-word illustration: colour. Centered the reading on the
  opening hedge, *Beiläufig gesprochen* — roughly speaking — arguing it
  is not modesty about confidence but a warning against literalism:
  "objects are colourless" is not a report on a missing paint job, since
  2.0231 already ruled out asking a bare object for a material property
  in the first place. Colour is borrowed as the easiest-to-picture
  material property to stand for the whole excluded class, then
  immediately hedged because even the negative ascription still sounds
  like a property claim. Noted this is Wittgenstein's own show-don't-say
  method (4.121) arriving four thesis-numbers early, in service of an
  idea that was never really about paint.
- Zen note compares Locke's primary/secondary quality distinction
  (*Essay Concerning Human Understanding* II.viii): colour as the
  textbook secondary quality, not resembling anything in the object
  itself. Disanalogy is load-bearing: Locke still tethers colour to the
  object as a latent disposition grounded in its primary qualities
  (bulk, figure, texture), present even absent a perceiver; 2.0231's
  *erst* cuts that tether entirely — material properties aren't powers
  stored in any single object, they are only formed once objects are
  combined with other objects. Locke detaches colour from appearance but
  keeps it anchored to constitution; Wittgenstein has nowhere in a
  single object for such an anchor to sit. Confirmed via grep that Locke
  had not appeared in this project before today — flagged as
  set-aside-for-this-occasion in yesterday's method note, and spent here
  as planned.
